# 信号采集

英文版本：[signal-capture.md](signal-capture.md)。

数字协议时序使用逻辑分析仪；模拟完整性、电压、振铃、上升/下降时间、噪声或电源行为
使用示波器。

## 请求有效采集

明确：

- 信号和物理参考地。
- 预期空闲电平和协议模式。
- 与症状关联的触发条件。
- 足以分辨最短目标事件的采样率。
- 触发前后的采集窗口。
- 是否需要包含复位、片选、中断、使能或 power-good。
- 预期行为和实测偏差。

建议数字通道：

- SPI：SCK、MOSI、MISO、CS，以及可选 IRQ/ready。
- I2C：SCL、SDA，必要时加复位/中断。
- UART：TX、RX，可选 RTS/CTS 和复位。
- PWM：PWM 输出、使能、故障和反馈/触发。
- 复位/启动：NRST、power-good、启动配置、时钟和固件标记 GPIO。

根据最快时钟或最短脉冲选择采样率，通常应显著高于目标速率；数字检查常以至少 10 倍
作为有用起点。需要判断边沿位置或窄毛刺时继续提高。逻辑分析仪不能证明模拟信号完整性。

## 关联软件与硬件

只有在任务范围内且安全时才增加低干扰标记 GPIO 或时间戳。把波形与串口日志、中断、
DMA 状态或调试器快照关联。定位完成后清理临时插桩，除非它被正式保留为诊断功能。

## 停止猜测

当问题涉及物理时序、总线所有权、边沿缺失、复位脉宽、片选顺序、总线争用或电压行为时，
请求采集。源码描述的是设计意图，波形显示的是板卡实际行为。
