# 安全边界

英文版本：[safety-boundaries.md](safety-boundaries.md)。

## 影响等级

| 等级 | 示例 | 默认处理 |
| --- | --- | --- |
| 0：离线 | 读取源码、map、ELF 元数据、已有日志 | 在任务范围内安全执行 |
| 1：枚举 | 列出工具、target、USB 探针 | 低影响；确认选择对象 |
| 2：连接/读取 | 连接探针，不主动暂停地读取状态 | 可能扰动目标；记录影响 |
| 3：暂停快照 | halt、读取核心状态、go | 中断实时运行；保持短暂并恢复 |
| 4：复位 | 软件/系统/硬件复位 | 丢失易失状态；需要对应意图 |
| 5：写入/编程 | 写寄存器/内存、选项字节、擦除/烧录 | 需要明确目的和授权 |

## 暂停纪律

- 说明 halt 会暂停 RTOS 调度、UART、屏幕刷新、网络、定时器、看门狗喂养和其他
  实时行为。
- 时序敏感或安全相关的实时测试中，除非用户接受干扰，否则避免暂停。
- 优先使用以 `go` 结束的一次性采集。
- 采集失败时，尝试单独恢复命令，并报告是否确认恢复。
- 不要在所有权不清楚的交互会话中让目标长期保持暂停。

## 复位纪律

- 复位原因重要时，先保存 Fault 寄存器、异常栈帧、最后日志和复位原因证据。
- 只有确认 NRST 接线后才使用硬件复位。
- 不能把复位描述为只读；它会改变执行和 RAM 状态。
- 复位后验证启动和心跳；复位命令成功本身不是功能验证。

## 地址和寄存器纪律

- 根据匹配符号、map、SVD 或器件文档确定地址。
- 检查访问宽度、对齐、权限和读取副作用。
- 不得使用从其他构建或 MCU 复制的地址。
- 区分读取和写入；“检查”请求不授权写操作。

## 共享工具和硬件

- 检查 Keil、pyOCD、OpenOCD、厂商下载器或其他 IDE 是否占用探针。
- 所有权不清楚时不要反复重连。
- 连接多个板卡或探针时，操作前确认目标身份。
- 如果调试器连接本身可能改变症状，将电气问题升级为波形采集。
